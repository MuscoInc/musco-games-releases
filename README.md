# Musco Games for Android

Download the Musco Games app here if you can't get it from Google Play yet.

**[Download the latest version](https://github.com/MuscoInc/musco-games-releases/releases/latest)**

On the release page, open **Assets** and tap the file ending in `.apk`.

## Before you start

- You need Android 7.0 or newer.
- The file is about 170 MB, so use Wi-Fi if you can.
- This is the same app Google Play installs, signed by Google. When Musco Games is public on Google Play, Play will update this install. Nothing to remove or reinstall.

## Install

1. Download the `.apk` file from the latest release.
2. Open it from the download notification, or from **Files → Downloads**.
3. If your phone says installing unknown apps is not allowed, tap **Settings**, turn on **Allow from this source**, then go back and tap **Install**.
4. If Google Play Protect asks about the app, tap **More details → Install anyway**. It asks because the app didn't come from the Play Store.
5. Open Musco Games and sign in.

## Updates

- **Small fixes** reach the app on their own. Close the app fully and open it again, twice, to get the newest one.
- **Bigger updates** come as a new file on this page. Install it over the one you have: your account and data stay.
- **Once the app is public on Google Play,** Play keeps it up to date, like any other app.

## Already a tester on Google Play?

If the Play Store shows a blank page for Musco Games:

1. In the Play Store, tap your profile picture and switch to the Google account you joined testing with.
2. Open the testing link again.
3. Still blank? Wait a few hours after joining, then try again. Clearing the Play Store's storage can help (**Settings → Apps → Google Play Store → Storage → Clear cache**).

You can use the file from this page meanwhile. Play will take over updates later.

## Problems or feedback

In the app, go to **Profile → Settings → Get help**. Your phone's details are attached for us, which helps us fix things faster.
